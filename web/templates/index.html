🔍 How It Works

Persistence Finder scans your Mac for all known persistence mechanisms — places where software (or malware) can survive a reboot. It runs entirely locally, makes no network requests, and never modifies anything. Click ▶ New Scan to start. Results are saved to the scans/ folder and appear in the sidebar.

🛡️ What Gets Scanned (22 Techniques)

1. LaunchAgents
~/Library/LaunchAgents, /Library/LaunchAgents, /System/Library/LaunchAgents — programs that run at login
2. LaunchDaemons
/Library/LaunchDaemons, /System/Library/LaunchDaemons — system-wide background services
3. Login Items
Apps set to open at login via System Settings
4. Cron Jobs
Scheduled tasks via crontab and /etc/cron*
5. Shell Profiles
.zshrc, .bash_profile, /etc/profile — commands run on every shell open
6. Startup Items (Legacy)
/Library/StartupItems — old-style boot scripts
7. Kernel Extensions
.kext files — kernel-level drivers, highest privilege
8. System Extensions
Modern DriverKit extensions via systemextensionsctl
9. SSH Authorized Keys
~/.ssh/authorized_keys — backdoor remote access keys
10. At Jobs
One-time scheduled tasks via atd
11. Periodic Scripts
/etc/periodic/daily|weekly|monthly — maintenance scripts
12. Config Profiles (MDM)
Mobile device management profiles that can enforce settings
13. Emond Rules
/etc/emond.d — event monitor daemon, rarely used legitimately
14. XPC Services
~/Library/XPCServices — inter-process communication services
15. Login/Logout Hooks
com.apple.loginwindow LoginHook/LogoutHook — legacy scripts
16. Dylib Hijacking
DYLD_INSERT_LIBRARIES and .dylib files in app bundles
17. Dock Items
com.apple.dock.plist — persistent apps in the Dock
18. Spotlight Importers
.mdimporter bundles that run during indexing
19. Browser Extensions
Chrome, Safari, Firefox extensions
20. Sudoers
/etc/sudoers — privilege escalation rules
21. Unsigned Apps
Applications not signed by Apple or a known developer
22. Quarantine DB
Recently downloaded files from the internet

🤖 AI Analysis — False Positive Reduction

The scanner flags thousands of items as suspicious — most are legitimate Apple system files. The AI Analysis tab sends all suspicious items to your local AI model (via Ollama) in batches of 50. The AI identifies which ones are actually malicious vs false positives.

  1. Install Ollama and pull a model: ollama pull deepseek-r1
  2. Go to 🤖 AI Analysis tab, enter your Ollama URL, click Detect
  3. Select a model and click ⚡ Analyze — all batches run automatically
  4. Real threats appear as cards. Click 🔬 Investigate to auto-run a read-only command
  5. Back in Findings, check 🤖 Hide AI false positives to see only real threats

⚠️ Important Notes

  • This tool is read-only — it never modifies, deletes, or executes anything
  • Run with sudo for complete access to all system files
  • Not all suspicious items are malicious — always verify before taking action
  • The Investigate feature only runs safe commands: file, stat, ls, cat, codesign, spctl, etc.
  • AI analysis runs entirely on your local machine — no data leaves your system
